# ایستگاه چاپ Invora (چاپگر مرکزی)

سایت روی اینترنت است و چاپگر داخل دفتر. این برنامه‌ی کوچک روی کامپیوتری که چاپگر به آن وصل است اجرا
می‌شود و **خودش هر چند ثانیه از سایت می‌پرسد «کار چاپی داری؟»** — پس هیچ پورتی روی مودم باز نمی‌شود و IP
ثابت لازم نیست. اگر اینترنت قطع شود، کارها در صف سایت می‌مانند و با وصل شدن چاپ می‌شوند.

```
در Invora «چاپگر مرکزی» را می‌زنید → کار (رمزشده) در صف سایت می‌نشیند
→ این برنامه برش می‌دارد → با Edge/Chrome خودِ ویندوز PDF می‌سازد → روی چاپگر با اندازه‌ی دقیق کاغذ چاپ می‌کند
→ نتیجه (چاپ شد / خطا) در «تنظیمات عمومی ← چاپگر مرکزی» دیده می‌شود
```

## ۱. در سایت (یک بار)

«تنظیمات عمومی ← چاپگر مرکزی ← ساخت ایستگاه» (مثلاً «دفتر») و بعد دکمه‌ی
**«دانلود برنامه با همین توکن»**. در فایل ZIP نشانی سایت و توکن ایستگاه از قبل نوشته شده است.
(دکمه‌ی بالای همان کارت هم همیشه نسخه‌ی خالیِ برنامه را می‌دهد.)

## ۲. روی کامپیوتر چاپگر (ویندوز)

1. پایتون ۳٫۹ یا بالاتر را از python.org نصب کنید و تیک **Add Python to PATH** را بزنید.
2. فایل ZIP را باز کنید و **install-windows.bat** را اجرا کنید (اجازه‌ی Administrator می‌خواهد).
   - بسته‌های لازم نصب می‌شوند؛
   - برنامه به‌صورت **سرویس ویندوز** («Invora Print Station») نصب و روشن می‌شود و بعد از هر روشن
     شدن ویندوز خودش اجرا می‌شود — لازم نیست هر بار بازش کنید. اگر به هر دلیل سرویس نصب نشد،
     اجرای خودکار با ورود به ویندوز (Task Scheduler) تنظیم می‌شود.
3. صفحه‌ی **http://localhost:8766** باز می‌شود: برای هر چاپگر بگویید **الان چه کاغذی داخلش است**
   (A4، A5، برچسب ۱۰۰×۱۵۰، حرارتی ۵۰×۳۰ …)، یکی را پیش‌فرض کنید و «چاپ آزمایشی» بزنید.

### اگر نصب در «Installing required packages» گیر کرد یا خطا داد

- برنامه‌ی نصب حالا پیشرفت دانلود بسته‌ها را نشان می‌دهد و اگر pypi.org کند یا بسته بود، خودش سراغ آینه‌های
  ایرانی (Runflare، لیارا، hmirror) می‌رود. همه‌ی جزئیات در فایل `install.log` کنار برنامه نوشته می‌شود.
- اگر هیچ‌کدام جواب نداد، اینترنت یا VPN را بررسی کنید، یا در همان پوشه دستی نصب کنید و دوباره
  install-windows.bat را اجرا کنید:
  ```
  py -3 -m pip install -i https://mirror-pypi.runflare.com/simple -r requirements.txt
  ```
- اگر پیام «Python was not found» آمد ولی پایتون نصب است: Settings ← Apps ← Advanced app settings ←
  App execution aliases و «python.exe» و «python3.exe» (میان‌برهای Microsoft Store) را خاموش کنید.

> **چاپگرهای شبکه‌ای/اشتراکی:** سرویس با حساب SYSTEM اجرا می‌شود و چاپگری را که فقط برای حساب شما
> وصل شده نمی‌بیند. اگر چاپگری در فهرست نبود: `services.msc` ← «Invora Print Station» ← Properties ←
> Log On ← «This account» و حساب ویندوز خودتان، سپس Restart.

حذف سرویس: `python agent.py stop` و بعد `python agent.py remove` (در Command Prompt با دسترسی Administrator).
اجرای دستی بدون سرویس: `run-windows.bat` یا `python agent.py`.

## لینوکس و مک

`python3 -m pip install -r requirements.txt` و `python3 agent.py` (چاپ با `lp`). برای اجرای خودکار یک
سرویس systemd یا LaunchAgent بسازید که همین دستور را اجرا کند.

## روش چاپ هر چاپگر

| روش | کی |
|---|---|
| خودکار | اگر SumatraPDF نصب باشد برای چاپگر کاغذی از آن، وگرنه «مستقیم». |
| مستقیم | بدون برنامه‌ی جانبی؛ صفحه با اندازه‌ی دقیق و وسط کاغذ روی چاپگر کشیده می‌شود (GDI ویندوز). |
| SumatraPDF | PDF با «بدون تغییر اندازه» چاپ می‌شود. |
| TSPL | چاپگرهای حرارتی برچسب سازگار با TSC (ZEC، Xprinter…): اندازه و فاصله‌ی برچسب را خود برنامه به چاپگر می‌دهد؛ دقیق‌ترین حالت برای برچسب. |

اگر برچسب حرارتی چرخیده چاپ شد، «چرخش» آن چاپگر را ۹۰ یا ۲۷۰ کنید.

## امنیت

محتوای هر کار چاپ روی سرور با کلیدی رمز شده که از توکن همین ایستگاه ساخته می‌شود؛ سایت آن را فقط در
لحظه‌ی فرستادن کار (بعد از ورود شما) دارد و پس از «چاپ شد» محتوا از سرور پاک می‌شود. توکن را مثل رمز
نگه دارید؛ اگر لو رفت، ایستگاه را در سایت حذف و دوباره بسازید.
