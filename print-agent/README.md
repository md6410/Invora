# ایستگاه چاپ Invora (چاپگر مرکزی)

سایت روی اینترنت است و چاپگر داخل دفتر. این برنامه‌ی کوچک روی کامپیوتری که چاپگر به آن وصل است اجرا
می‌شود و **خودش هر چند ثانیه از سایت می‌پرسد «کار چاپی داری؟»** — پس هیچ پورتی روی مودم باز نمی‌شود و IP
ثابت لازم نیست. اگر اینترنت قطع شود، کارها در صف سایت می‌مانند و با وصل شدن چاپ می‌شوند.

```
در Invora «چاپگر مرکزی» را می‌زنید → کار (رمزشده) در صف سایت می‌نشیند
→ این برنامه برش می‌دارد → با Edge/Chrome خودِ ویندوز PDF می‌سازد → روی چاپگر با اندازه‌ی دقیق کاغذ چاپ می‌کند
→ نتیجه (چاپ شد / خطا) در «تنظیمات عمومی ← چاپگر مرکزی» دیده می‌شود
```

## ۱. در سایت (یک بار)

«تنظیمات عمومی ← چاپگر مرکزی ← ساخت ایستگاه» (مثلاً «دفتر») و بعد دکمه‌ی
**«دانلود برنامه با همین توکن»**. در فایل ZIP نشانی سایت و توکن ایستگاه از قبل نوشته شده است.
(دکمه‌ی بالای همان کارت هم همیشه نسخه‌ی خالیِ برنامه را می‌دهد.)

## چند سایت روی یک ایستگاه (نسخه‌ی ۲٫۱)

یک ایستگاه چاپ می‌تواند به **چند سایت Invora** سرویس بدهد؛ لازم نیست برای هر سایت جداگانه نصب کنید.
هر سایت نشانی API و توکن ایستگاهِ خودش را دارد و برنامه برای هر کدام یک رشته‌ی جدا دارد؛ کار هر سایت با توکن همان
سایت رمزگشایی می‌شود و نتیجه‌اش به همان سایت گزارش می‌شود. چاپگرها مشترک‌اند و کارها یکی‌یکی چاپ می‌شوند.

- **از صفحه‌ی تنظیمات** (http://localhost:8766): بالای صفحه جدول «سایت‌هایی که به این ایستگاه چاپ وصل‌اند» است؛ برای افزودن
  سایت تازه نشانی (`https://…/print-api.php`) و توکن را در آخرین سطر بنویسید و «ذخیره» بزنید. برای هر سایت می‌شود
  نام، چاپگر پیش‌فرضِ همان سایت، فعال/خاموش و حذف را تعیین کرد و وضعیت اتصالش را دید.
- **با فایل ZIP هر سایت**: «دانلود برنامه با همین توکن» را از سایت دوم هم بگیرید و `InvoraPrint.exe` را اجرا کنید؛ سایتِ آن ZIP
  به فهرست سایت‌های نصب‌شده **اضافه** می‌شود (سایت‌ها و کاغذ چاپگرها پاک نمی‌شوند).
- `config.json` قدیمی (فقط `api_url` و `token`) خودکار به فهرست `sites` منتقل می‌شود:

```json
{ "sites": [
    {"name": "دفتر", "api_url": "https://a.example.com/print-api.php", "token": "…", "enabled": true},
    {"name": "فروشگاه", "api_url": "https://b.example.com/print-api.php", "token": "…", "enabled": true, "printer": "Zebra"} ] }
```

## ۲. روی کامپیوتر چاپگر (ویندوز) — بدون هیچ کار دستی

1. فایل ZIP را باز کنید (Extract All) و روی **InvoraPrint.exe** دوبار کلیک کنید و «Yes» بزنید.
   اگر ویندوز گفت «Windows protected your PC»، «More info» و بعد «Run anyway» را بزنید
   (برنامه امضای تجاری ندارد؛ همین یک بار می‌پرسد).
2. تمام. برنامه:
   - خودش را در `C:\ProgramData\InvoraPrint` نصب می‌کند و نشانی سایت و توکن را از `config.json` کنارش برمی‌دارد؛
   - در Task Scheduler ثبت می‌شود تا با **ورود به ویندوز** خودش اجرا شود و اگر بسته شد هر ۵ دقیقه خودش
     دوباره بالا بیاید؛
   - میان‌بر «Invora Print Station» را روی دسکتاپ می‌گذارد و صفحه‌ی تنظیمات **http://localhost:8766** را باز می‌کند.
3. در همان صفحه برای هر چاپگر بگویید **چه کاغذی داخلش است** و «چاپ آزمایشی» بزنید.

پایتون، pip و دانلود از اینترنت لازم نیست: InvoraPrint.exe همه‌چیز را دارد. این فایل را GitHub Actions روی
ویندوز می‌سازد و پیش از انتشار می‌آزماید (نصب، اجرای خودکار، ساخت PDF با Edge، به‌روزرسانی، حذف).

- به‌روزرسانی: فایل تازه را از سایت بگیرید و همان‌طور اجرا کنید؛ تنظیمات می‌ماند.
- حذف: در پوشه‌ی برنامه `InvoraPrint.exe uninstall`.
- گزارش و تنظیمات: `C:\ProgramData\InvoraPrint\agent.log` و `config.json`.
- عیب‌یابی: `InvoraPrint.exe selftest --out test.json` همه‌ی بخش‌ها را می‌آزماید.

### نسخه‌ی پایتونی (لینوکس، مک، یا اگر EXE نخواستید)

`install-windows.bat` و `run-windows.bat` هنوز هستند و روی ویندوزِ دارای پایتون هم کار می‌کنند.

> **چرا با ورود به ویندوز و نه پیش از آن؟** Microsoft Edge که صفحه را به PDF تبدیل می‌کند، در حساب SYSTEM ویندوز
> اصلاً اجرا نمی‌شود. برای همین ایستگاه در حساب کاربرِ واردشده اجرا می‌شود؛ فایده‌اش این است که چاپگرهای شبکه‌ای
> و اشتراکیِ همان کاربر هم دیده می‌شوند. کارهایی که وقتی کسی وارد ویندوز نشده برسند در صف سایت می‌مانند و با ورود
> چاپ می‌شوند. اگر کامپیوتر چاپ همیشه روشن است، «ورود خودکار ویندوز» (autologon) را برایش روشن کنید.
>
> **(نسخه‌ی پایتونی با سرویس ویندوز):** سرویس با حساب SYSTEM اجرا می‌شود و چاپگری را که فقط برای حساب شما
> وصل شده نمی‌بیند. اگر چاپگری در فهرست نبود: `services.msc` ← «Invora Print Station» ← Properties ←
> Log On ← «This account» و حساب ویندوز خودتان، سپس Restart.

حذف سرویس: `python agent.py stop` و بعد `python agent.py remove` (در Command Prompt با دسترسی Administrator).
اجرای دستی بدون سرویس: `run-windows.bat` یا `python agent.py`.

## لینوکس و مک

`python3 -m pip install -r requirements.txt` و `python3 agent.py` (چاپ با `lp`). برای اجرای خودکار یک
سرویس systemd یا LaunchAgent بسازید که همین دستور را اجرا کند.

## روش چاپ هر چاپگر

| روش | کی |
|---|---|
| خودکار | اگر SumatraPDF نصب باشد برای چاپگر کاغذی از آن، وگرنه «مستقیم». |
| مستقیم | بدون برنامه‌ی جانبی؛ صفحه با اندازه‌ی دقیق و وسط کاغذ روی چاپگر کشیده می‌شود (GDI ویندوز). |
| SumatraPDF | PDF با «بدون تغییر اندازه» چاپ می‌شود. |
| TSPL | چاپگرهای حرارتی برچسب سازگار با TSC (ZEC، Xprinter…): اندازه و فاصله‌ی برچسب را خود برنامه به چاپگر می‌دهد؛ دقیق‌ترین حالت برای برچسب. |

اگر برچسب حرارتی چرخیده چاپ شد، «چرخش» آن چاپگر را ۹۰ یا ۲۷۰ کنید.

## امنیت

محتوای هر کار چاپ روی سرور با کلیدی رمز شده که از توکن همین ایستگاه ساخته می‌شود؛ سایت آن را فقط در
لحظه‌ی فرستادن کار (بعد از ورود شما) دارد و پس از «چاپ شد» محتوا از سرور پاک می‌شود. توکن را مثل رمز
نگه دارید؛ اگر لو رفت، ایستگاه را در سایت حذف و دوباره بسازید.
